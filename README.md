# OrderSprout

A small order book for home bakers and handmade-product sellers.

## Project status

Planning and environment setup. Application features are being added in small milestones.

## First version planned

- Add customer orders and delivery dates.
- Record total price and cumulative payments received.
- Update order status.
- Calculate the remaining balance.
- Save orders in SQLite.

## Development approach

Each feature has a branch, a small change, appropriate checks, updated documentation and a pull request.
CI and deployment will be introduced as separate milestones.

See [requirements](docs/requirements.md) and [development log](docs/development-log.md).
